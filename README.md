# CT3-nx

An unofficial native port of Crazy Taxi 3: High Roller (original Xbox, USA) to PC and Nintendo Switch homebrew, made
by static recompilation with xboxrecomp. Work in progress: nothing runs yet.

This repository contains no game code or data. You need your own copy of the game.

Built on xboxrecomp (sp00nznet, MIT) through burnout3-sw (antoxa2584x, MIT), CoD-nx and sheroes-nx. See LICENSE and
